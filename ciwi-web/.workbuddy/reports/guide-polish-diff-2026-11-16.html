1 · How to Translate Shopify Review, Loyalty & Chat App Content

/guides/how-to-translate-shopify-review-apps-content/
改前的问题是标题与内容错位，不是文笔。标题承诺 review / loyalty / chat 三类应用，正文 80% 只讲评价；会员和聊天被塞进检查清单最后两条——一条 205 字符、一条 334 字符。这篇排在第 4.7 位、237 次展示、0 点击，落地页答不了标题问到的东西。

方案块

方案块是这一篇最关键的改动。改前的三个选项是模板通用项——人工 / 翻译应用 / API 自定义开发，换任何一个主题都能原样贴上去，和「评价应用」没有任何关系。改后的三个选项对应商家真实会撞上的三条路：文案归应用管的、归主题管的、归用户内容管的。
改前 · 3 个选项
Manual translation (in-house or freelancer)
  • Human nuance preserves authenticity
  • Selective translation of top reviews
  • No recurring fee for a few hero reviews
  • Slow for hundreds of reviews
  • Hard to keep tone consistent
  • User reviews update constantly
Shopify translation app (Translate & Adapt / Ciwi)
  • Bulk-translates text exposed to the translation tool
  • Lets you verify supported third-party widget strings on the storefront
  • Helps keep merchant reply terminology consistent
  • Recurring subscription cost
  • Machine-translated reviews can read flat
  • Top reviews still need a human review pass
Custom build with the Shopify API
  • Full control over the review pipeline and storage
  • Integrates with your review platform
  • No per-app markup at scale
  • Requires development resources
  • Ongoing maintenance burden
  • Slower to launch than an app
改后 · 3 个选项
Translate the app-owned strings inside the app
  • Loyalty and chat apps usually ship per-language fields for greetings, reward names and redemption buttons
  • Widget labels set here survive theme updates and app re-publishes
  • A handful of strings, no export or import round trip
  • Coverage is whatever the app exposes, not whatever Shopify can translate
  • Every app keeps its language settings in a different place
  • Review text often has no per-language field at all
Translate theme and Shopify-owned strings with Translate & Adapt
  • Reaches widget chrome that lives in theme locale files
  • Shares one glossary with the rest of the storefront
  • Keeps Verified buyer and star labels consistent with product pages
  • Only covers content that is a Shopify translatable resource
  • Text injected by an app at runtime stays in the source language
  • Does not reach customer reviews, which are not a Shopify resource
Translate the high-value user content by hand
  • Keeps tone natural exactly where trust is decided
  • Lets you label a review as translated instead of passing machine output off as native
  • Stays affordable when you limit it to hero reviews and your replies
  • Every new review reopens the decision
  • Cost per review is hard to predict
  • Needs a reviewer who knows the product, not just the language

覆盖范围

改前 · 3 类
  1. Critical：Review widget labels, Review request emails, Merchant responses
  2. Important：Top customer reviews, Star-rating filters & sort labels, Q&A sections
  3. Optional：Photo review captions, Featured-review banners
改后 · 3 类
  1. Critical：Review widget labels (Verified buyer, Write a review, star filters), Merchant replies under reviews, Loyalty: reward names, point balance label, redemption button, Chat: greeting, offline message, quick replies
  2. Important：Review request emails (subject, body, button), Q&A answers written by you, Loyalty tier names and expiry notices
  3. Optional：Top customer reviews, Photo captions and featured-review banners

检查清单

改前 · 10 条
  1. Inventory every review surface — on-page widgets, request emails, and the review app's admin text.
  2. Export widget labels, email templates, and your merchant replies into one sheet.
  3. Build a glossary for verified, rating, recommend, and your product names.
  4. Scope it: widget labels and emails first, then top reviews, then photos and captions.
  5. Pick a method — manual for a few hero reviews, app for bulk, API for custom pipelines.
  6. Human-review the top reviews you translate; authenticity matters more than speed here.
  7. Translate your merchant replies so concerns get answered in-language.
  8. Check the live widget renders correctly in the target language, including length and RTL.
  9. Loyalty apps: check the app settings for per-language point balances, reward names, and redemption buttons. Switch languages with a test member account and verify both the launcher and the redemption flow.
  10. Chat apps: check the app settings for locale rules, then configure greetings, offline messages, and quick replies. Switch storefront languages in a private window and test online and offline states separately. If the widget stays in the default language, check its locale support. Verify widget copy and live conversations separately.
改后 · 8 条
  1. List the three surfaces separately: review widget, loyalty panel, chat launcher. They almost never share settings.
  2. For each string, note whether it lives in the app's settings, the theme's locale file, or Shopify's translatable resources. That decides where you edit it.
  3. Open the app's own settings first: loyalty and chat usually expose per-language fields for greetings, reward names and buttons.
  4. Translate the theme-side chrome with Translate & Adapt so labels like Verified buyer match the rest of the storefront.
  5. Decide the review-text policy before touching it: widget chrome and your replies always, customer reviews selectively.
  6. Translate two or three hero reviews by hand and mark them as translated rather than presenting machine output as native copy.
  7. Switch the storefront language in a private window and walk all three surfaces, including the loyalty redemption flow and the chat offline state.
  8. Re-check after any app update or theme publish, because widget strings are the first thing to revert.
改前最后两条各是三句话挤成一段（205 / 334 字符），把会员和聊天两个应用硬塞进清单。改后三类应用各自成条，每条一个动作，最长 155 字符。

2 · How to Translate Shopify Cart & Mini-Cart

/guides/how-to-translate-shopify-cart-and-mini-cart/
这篇的问题最典型：方案块是模板套出来的。改前三个选项是「人工 / 翻译应用 / API 自定义开发」——同一组标题在 31 篇里原样复现。而购物车真正会卡住商家的是另一件事：一句话到底住在主题 locale 文件、写死的 section 标记，还是某个已装应用里。

摘要与开篇

字段改前改后
description Translate Shopify mini-cart text, cart buttons, and empty-cart messages so shoppers can review products and continue to checkout in their language.Fix the cart and mini-cart copy shoppers actually read: drawer buttons, free-shipping messages, empty states, and the wording handoff into checkout.
mainValue A repeatable method for localizing cart and mini-cart copy — the buttons, labels, and empty states that keep shoppers moving toward checkout.Work out where each cart string lives — theme locale file, hardcoded section markup, or an app — and verify the whole drawer in every language instead of only the cart page.
驱动 1 The cart is the last decision point before paymentThe drawer, not the cart page, is what most shoppers see
驱动 2 Mini-cart text often hides in theme codeCart copy is small, which is exactly why it gets skipped
驱动 3 Cart text must match the checkout that followsMoney and status messages break differently

方案块

改前是那组 31 篇共用的三段式。改后换成了购物车文案真实的三种归属：主题 locale 文件里、写死在 section 标记里、已装应用注入的。这三条路决定的是「去哪儿改」，而不只是「用什么方式翻」。
改前 · 3 个选项
Manual translation (in-house or freelancer)
  • Full control over every cart string including theme hardcodes
  • No cost for a small set of markets
  • Human nuance for calls-to-action
  • Mini-cart strings are easy to miss because they live in theme code
  • Slow to update when the theme changes
  • Inconsistent phrasing across markets without a glossary
Shopify translation app (Translate & Adapt / Ciwi)
  • Detects and translates cart strings across theme and Shopify
  • Keeps cart and checkout wording consistent
  • Auto-syncs when you change the theme or copy
  • Theme-specific strings may still need a manual check
  • Recurring subscription cost
  • Quality depends on engine and glossary setup
Custom build with the Shopify API
  • Full programmatic control of cart text via the Storefront API
  • Tight integration with a custom headless cart
  • No app markup at large scale
  • Requires developer resources and a custom storefront
  • Ongoing maintenance
  • Slower to launch than an app
改后 · 3 个选项
Translate the theme's cart locale strings
  • Covers most of the drawer when it is built from theme sections
  • Same glossary as product and collection pages
  • Survives theme updates better than edited markup
  • Only reaches strings the theme actually stores in its locale file
  • Hardcoded markup and inline JavaScript text stay untranslated
  • A custom or heavily modified theme may expose very little
Edit the hardcoded cart-drawer strings in the theme
  • Reaches the strings the locale file does not cover
  • No app needed for a handful of labels
  • Immediate, visible result in the drawer
  • Changes live in the theme and are lost on a theme update unless you keep a copy
  • Needs someone comfortable editing sections or snippets
  • Easy to break the amount or currency format inside a sentence
Handle the cart text an installed app owns
  • Covers upsell, bundle, subscription and currency widgets inside the cart
  • App settings usually expose their own per-language fields
  • Keeps app copy separate from theme copy, so updates do not collide
  • Each app has its own settings surface
  • Coverage depends on what the app exposes
  • Some apps inject text with no per-language option at all

覆盖范围

改前 · 3 类
  1. Critical：Cart & checkout buttons (CTA), Subtotal, tax, and shipping labels, Quantity & remove item labels, Empty-cart state text
  2. Important：Line-item labels (SKU, variant, unit price), Discount / promo code field, Continue-shopping links
  3. Optional：Upsell and cross-sell blocks, Gift note and delivery date fields
改后 · 3 类
  1. Critical：Checkout and continue buttons in the drawer and cart page, Subtotal, shipping, tax and total labels, Quantity, remove and update controls, Empty-cart message
  2. Important：Free-shipping progress message, Discount code field and its error messages, Line-item labels (variant, unit price, SKU), Continue-shopping link
  3. Optional：Upsell and cross-sell blocks inside the drawer, Gift note and delivery-date fields
改后「重要」一档从 3 项增到 4 项，补进折扣码输入框与报错文案——这是原文完全没提、但出错时购物者一定会看到的内容。

检查清单

改前 · 7 条
  1. Open your cart and mini-cart and capture every visible string, including the slide-out drawer.
  2. Check whether your theme hardcodes mini-cart text — inspect the cart-drawer section or use a translation app that scans theme strings.
  3. Translate the high-impact strings first: CTA button, subtotal, tax, and shipping labels.
  4. Localize quantity, remove, and empty-cart states — these are easy to overlook.
  5. Keep wording consistent with your checkout (button label, discount field, totals).
  6. Apply the same glossary you use on product pages so product names match.
  7. Test the full cart flow in each language, including adding, updating, and emptying the cart.
改后 · 8 条
  1. Open the drawer in a browser and screenshot it in the source language, with one item and with none. The empty state is the one nobody remembers.
  2. For each string, decide where it lives: theme locale file, section or snippet markup, or an installed app.
  3. Translate the theme locale strings first, then diff the drawer against your screenshot to see what stayed in the source language.
  4. Check the free-shipping message in each language, because it usually composes an amount into a sentence. Confirm the currency symbol and rounding still read correctly.
  5. Translate the error path, not just the happy path: an invalid discount code and a quantity of zero are the strings shoppers actually hit.
  6. Switch language with items already in the cart, rather than rebuilding the cart in the new language.
  7. Run the drawer on a phone viewport, where translated buttons wrap or get clipped.
  8. Re-check after the next theme update, since hardcoded fixes do not survive it.
