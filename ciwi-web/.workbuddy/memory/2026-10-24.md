## 关键结论（踩坑记录）

- **`skipTrailingSlashRedirect: true` 会导致无限自跳**：实测 `/about` → 308 → `/about`（带 Refresh 头），
  同时 `/deepl` 反而变成一跳。已回退该配置，不要再试（除非在 Nginx/CDN 层做）。
- **Next 在 middleware 之前做尾斜杠规范化**，所以 next.config 里成对的「无斜杠 source」是死代码，
  旧 URL 的无斜杠形态必然两跳；带斜杠形态现在一跳。
- 全站回归：本地 standalone 跑 sitemap 1691 条 → 全部 200、0 跳转（`node scripts/audit-redirects.mjs --sitemap`）。

### 双斜杠 `playbook//keyword/` 的根因（已确认，代码已修）

- `src/content/use-cases.ts` 的 `getProductPlaybookHref`：
  - `566cc63c`(09-11) 返回 `/products/<slug>/playbook`
  - **`adaceea8`(09-20) 改成 `/products/<slug>/playbook/`（多尾斜杠）→ 所有 `${href}/keyword/<kw>` 产出 `playbook//keyword/`**
  - `7c6e4090`(09-24) 改回，修复
- GSC 趋势线对应：9/19=163 → 9/22=365，正是那 4 天窗口。
- 线上现状干净：7 个入口页 `playbook//` 计数均为 0。

### 重要：两跳压不成一跳（应用层）

本地实测：Next 的 `//` 压平 + 尾斜杠归一化**都在 middleware 之前**执行，middleware 只能补最后一跳。
`/deepl`=2 跳 / `/deepl/`=1 跳；`/playbook//keyword/<kw>`=2 跳 / `.../<kw>/`=1 跳。
→ 只能在 Nginx / Cloudflare 层做，仓库里做不到。不要再尝试 `skipTrailingSlashRedirect`。

### 14 条 zh-cn 指南跳英文

`src/app/guides/[slug]/page.tsx:1429` 的 `permanentRedirect`：slug 在当前 locale 下不可用时跳 fallbackLocale。
根因是内容状态：`localization_guides.zh-cn.json` 37 条里 25 条仍是 `translationStatus: ai-draft` + `status: draft`
（部分标题为 `[TODO zh-cn] ...` 占位），被 `src/content/guide-content.ts` 的 `isIndexable()` 过滤掉。
**不是 bug，是译文没做完**；补完译文自然解决。
