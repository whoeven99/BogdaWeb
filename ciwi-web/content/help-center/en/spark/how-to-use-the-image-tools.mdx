Image Studio groups the visual tools into two workflows: generate and translate.

## Generate an image

Use the generate tab to create an image from a text prompt. This is useful for product visuals, banners, and campaign assets when you need a new image quickly.

## Translate text inside an image

Use the translate tab to localize text that is embedded in an image, such as a banner or a product graphic. Choose the target language and review the translated output before downloading.

## Track image tasks

Image generation and translation jobs appear in the task list. You can batch multiple requests and monitor their status from one place.
