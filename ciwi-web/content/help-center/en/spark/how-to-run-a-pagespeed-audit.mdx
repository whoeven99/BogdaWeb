Run a Shopify PageSpeed audit to review storefront performance for a specific page. Spark lets you choose the URL and mobile or desktop analysis, then inspect the resulting report.

## 1. Choose a URL

Enter the page you want to audit, or use the store URL pre-filled by Spark.

## 2. Choose a strategy

Select **mobile** or **desktop**. Mobile is usually the more important check for storefront performance.

## 3. Choose a report locale

If you are auditing a localized page, set the report locale so the results match the version shoppers actually see.

## 4. Read the scores

The report is split into categories, each with its own score. Review the metrics and the audit items to see which fixes will have the most impact.
