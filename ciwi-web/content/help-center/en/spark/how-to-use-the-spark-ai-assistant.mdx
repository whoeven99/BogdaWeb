The AI assistant is the main entry point in Spark. Use chat to ask about the store and to launch content or image tasks.

## Ask about store data

Ask questions about the store and its performance, such as revenue, orders, conversion, or traffic. Spark queries Shopify data and returns a concise answer with the relevant signals.

## Generate and improve content

Ask Spark to generate a product description or improve existing copy. The assistant can produce an editable draft that you review before publishing.

## Translate and generate images

Spark can translate text inside an image and generate images from a prompt. Use the image tools when you need a localized banner or a new product visual.

## Turn answers into tasks

When an answer suggests an action, you can turn it into an AI or automation task and track it from the task list. This keeps insights connected to the follow-up work.
