Product Improve helps you generate and refine product descriptions without writing each one from scratch.

## 1. Select a product

Choose the product you want to improve with the product selector. Spark loads the product and its current copy as the starting point.

## 2. Choose a language

Pick the target language for the description. This is useful when you are preparing localized product copy.

## 3. Generate or improve

Ask Spark to generate a new description or improve the existing one. Spark returns an editable draft that you review before applying.

## 4. Check the quality score

Spark can score product quality and surface the areas that need attention, so you know where to focus your edits.

## 5. Track tasks

Generated and improvement jobs appear in the task list. Use batch tasks when you want to improve multiple products at once.
