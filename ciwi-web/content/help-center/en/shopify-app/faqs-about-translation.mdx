## Can I review translations before publishing?

Yes. The current workflow is designed for that. Create jobs in **Translate v4**, review important items in **Manage Translation**, and publish the target language only after you are satisfied with the result.

## Can I overwrite existing translations?

Yes. The v4 task flow includes an overwrite option for cases where you want the new run to replace older translated content. Use it carefully if your store already has hand-edited copy that you want to preserve.

## Can I create jobs for multiple target languages?

Yes. You can select multiple target languages in **Translate v4**. Ciwi then creates one independent job per language so progress, retrying, and failures stay easier to manage.

## Does auto-translate cover everything?

No. Auto-translate is helpful for supported modules, but not every kind of content should be fully hands-off. For example, email templates and important campaign copy usually deserve manual review.

## Where do I check credits before starting?

Use the estimate in **Translate v4** and check your available credits on the **Pricing** page. If the task is larger than your current balance, the app can guide you to buy more credits.

## How do I get help if something looks wrong?

Ciwi includes an in-app support flow. You can contact support from inside the app, and the support API also accepts message attachments for troubleshooting.
