The **Language** page is where you manage the target languages that Ciwi can work with for your shop.

## What you can do on the Language page

- Add a new target language.
- See language-level translation coverage and status.
- Publish or unpublish a language for storefront use.
- Turn automatic translation on or off for supported languages.

## Typical flow

1. Add the target language you want to support.
2. Run a translation job for that language in **Translate v4**.
3. Review key content in **Manage Translation**.
4. Publish the language when the storefront is ready.

## About automatic translation

Automatic translation is controlled per target language. It is useful for keeping supported content updated after your first setup, but you should still review important content such as flagship products, campaigns, or market-specific messaging.

## Recommendation

Start with the languages tied to your real priority markets. It is easier to control terminology, pricing, and storefront quality when you scale one market at a time.
