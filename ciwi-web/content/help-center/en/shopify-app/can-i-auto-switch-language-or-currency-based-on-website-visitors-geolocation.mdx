Yes. The current app includes a geolocation setting on the switcher side, so shoppers can land on a more suitable language or currency automatically.

## When it helps

- You serve shoppers from multiple countries and want the first storefront view to feel more local.
- You already know which markets and currencies you support.
- You want less friction before a shopper starts browsing.

## What needs to be ready first

- Your target languages must already exist on the **Language** page.
- Your currencies should already be configured if you want currency switching too.
- The storefront switcher should already be added to the theme, because automatic switching should never remove the shopper's manual choice.

## Recommended way to use it

Use geolocation as a **default suggestion**, not as a hard lock. Keep the language and currency switcher visible so visitors can change the storefront manually when the automatic match is not what they want.

## Before going live

Test your main markets, fallback behavior, and mobile storefront layout. If a market is missing a dedicated language or currency setup, shoppers will see your default fallback instead.
