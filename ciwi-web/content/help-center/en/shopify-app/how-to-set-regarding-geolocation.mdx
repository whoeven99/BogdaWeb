Use this order when you enable geolocation in the current Ciwi setup.

## Step 1: Confirm languages

Make sure the target languages already exist on the **Language** page and the storefront actually has the language versions you expect to show.

## Step 2: Confirm currencies

If you want currency switching too, finish the **Currency** page setup first, including exchange rate and rounding behavior.

## Step 3: Confirm the switcher

The storefront switcher should already be installed in the Shopify theme and visible to shoppers. Automatic behavior should support the switcher, not replace it.

## Step 4: Turn on geolocation

Open the **Switcher** page and enable the geolocation option. Then test the storefront carefully across your main markets.

## Step 5: Verify fallback behavior

If a visitor's region does not map cleanly to one of your configured languages or currencies, the storefront falls back to your default setup. Make sure that fallback still feels reasonable.
