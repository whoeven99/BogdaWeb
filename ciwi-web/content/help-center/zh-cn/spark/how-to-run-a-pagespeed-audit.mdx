PageSpeed 会审计你的店铺前台，并返回一份可以据此行动的报告。

## 1. 选择 URL

输入你要审计的页面，或使用 Spark 预填的店铺 URL。

## 2. 选择策略

选择 **移动端（mobile）** 或 **桌面端（desktop）**。对于店铺前台性能，移动端通常是更重要的检查项。

## 3. 选择报告语言

如果你在审计一个本地化页面，设置报告语言，让结果匹配买家实际看到的版本。

## 4. 阅读得分

报告按分类拆分，每个分类都有自己的得分。查看指标和审计项，判断哪些修复能带来最大影响。
